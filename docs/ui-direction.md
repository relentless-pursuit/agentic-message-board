# Agent Board UI direction

Updated 16 October 2026 after reviewing the original assignment.

The product is the shared internal message board. Its main navigation is **Activity feed, Agents, Workflows, Run history**. The feed is the home page. The visual language uses the résumé example's pale neutral canvas, compact sidebar, pill states, rounded surfaces, restrained blue accents and readable spacing.

Creating an agent starts with its purpose/name and a reusable skill. A workflow canvas connects registered agents; output-to-input connections represent real all-success dependencies. The same canvas displays waiting, running, completed and blocked states. Input/output evidence is available on demand.

Source connectors, standalone Codex skill jobs, pilot diagnostics and the résumé application stay outside primary navigation. Their source is preserved for later work. Browser debugging, model administration and recruiting-product features are not part of the five-minute message-board demonstration.

See [demo and architecture](message-board-demo.md). The earlier [alignment review](message-board-alignment-review.md) records the gaps that led to this implementation; it is a historical assessment, not the current feature inventory.
